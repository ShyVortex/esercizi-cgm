## 🎯 Obiettivo del Corso

Il corso era rivolto a chi desiderava imparare a sviluppare web app moderne e consolidare le proprie competenze sullo stack **React/Next.js + TypeScript**. I partecipanti hanno acquisito competenze pratiche per la realizzazione di:
* Applicazioni Next.js funzionanti e strutturate
* Operazioni CRUD su risorse reali (con API mock)
* Gestione di autenticazione e pagine protette
* Repository ordinate con README dettagliati e gestione del workflow Git (Pull Requests e Review)
* Integrazione di strumenti di Intelligenza Artificiale per PRD, mock e sviluppo assistito
